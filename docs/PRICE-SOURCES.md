# اتصال منابع قیمت پس از استقرار

برنامه بدون هیچ منبع خارجی هم کار می‌کند: قیمت دستی همیشه فعال است و هیچ قیمت قدیمی یا نامعتبری به‌عنوان قیمت زنده نمایش داده نمی‌شود.
بقیهٔ منابع **اختیاری** هستند و از «منابع قیمت» در رابط کاربری فعال می‌شوند.

## ۱) پیش از شروع: دسترسی شبکهٔ سرور

* سرور باید بتواند **خروجی HTTPS/HTTP** به میزبان هر منبع بزند. سرویس systemd محدودیتی روی اتصال خروجی ندارد؛ فایروال سرور/ارائه‌دهنده را بررسی کنید.
* **سرور خارج از ایران:** برخی سرویس‌های ایرانی (TSETMC، بیت‌پین و …) ممکن است درخواست از IPهای خارج از ایران را مسدود یا محدود کنند. اگر «تست اتصال» روی سرور آلمان/اروپا شکست خورد، سرور داخل ایران یا یک مسیر خروجی داخل ایران لازم است. این موضوع در محیط ساخت قابل آزمودن نبود.
* **Iran Market Data** از `raw.githubusercontent.com` دریافت می‌کند (فایل عمومی). از ایران ممکن است بسته باشد؛ آینهٔ jsDelivr را در `IRANMARKET_URL` بگذارید (ممکن است تا ~۱۲ ساعت کش داشته باشد و داده «قدیمی» علامت بخورد).
* ابتدا از خود سرور بررسی کنید:
  ```bash
  curl -sS -m 10 -o /dev/null -w '%{http_code}\n' https://cdn.jsdelivr.net/gh/iran-market/iran-market.github.io@main/data/latest-toman.json
  curl -sS -m 10 -o /dev/null -w '%{http_code}\n' https://api.bitpin.ir/
  ```

## ۲) فعال‌سازی هر منبع

۱. وارد برنامه شوید (Basic Auth اگر فعال است) ← صفحهٔ **«منابع قیمت»**.
۲. روی کارت منبع، «ویرایش» را بزنید: آدرس، نوع احراز هویت و کلید API (در صورت نیاز) را وارد کنید.
۳. **«تست اتصال»** را بزنید؛ نتیجه، زمان پاسخ و خطا نمایش داده می‌شود.
۴. منبع را **فعال** کنید و بازهٔ به‌روزرسانی را بگذارید.
۵. در فرم هر دارایی (یا «اولویت منابع») ترتیب منابع را تعیین کنید: مثلاً TSETMC ← Iran Market ← دستی.
۶. «دریافت دستی» را یک‌بار اجرا و در جدول قیمت‌ها اعتبار/زمان را ببینید. قیمت خودکار فقط با «تأیید خودکار» منبع یا تأیید دستی وارد ارزش‌گذاری می‌شود.

| منبع | کلید | نکته |
|---|---|---|
| دستی | — | همیشه فعال |
| TSETMC | ندارد | نشانی‌ها در `TSETMC_BASE_URL`/`TSETMC_SERVICE_URL`؛ با «تست اتصال» راستی‌آزمایی کنید (از کلاینت متن‌باز گرفته شده و با سرویس زنده آزموده نشده) |
| Bitpin | ندارد | `BITPIN_BASE_URL`؛ فقط بازارهای تکی مثل `BTC_IRT` |
| Iran Market Data | ندارد | به‌طور پیش‌فرض **غیرفعال**؛ از صفحهٔ «بازار جامع ایران» فعال کنید و نماد را با تأیید صریح به دارایی وصل کنید |
| StreamData / Servix | دارد | آدرس پیش‌فرض ندارند؛ آدرس و کلید را از سرویس‌دهنده بگیرید |
| Custom API | اختیاری | هر API با پاسخ JSON؛ مسیر JSONPath و واحد را تنظیم کنید |

## ۳) کلیدهای API

* کلید را در صفحهٔ «منابع قیمت» وارد کنید. **فقط‌نوشتنی** است: با Fernet رمز می‌شود، به مرورگر برنمی‌گردد (فقط `has_api_key`) و در پشتیبان JSON نیست.
* **رمزنگاری با `SECRET_KEY`** انجام می‌شود. این مقدار را تغییر ندهید و گم نکنید (در `.env` است و باید در پشتیبان کامل `--with-secrets` باشد). با تغییر آن کلیدهای ذخیره‌شده خوانده نمی‌شوند و باید دوباره وارد شوند.
* روش جایگزین: `STREAMDATA_API_KEY`/`SERVIX_API_KEY` و آدرس‌ها در `.env` (فقط روی سرور؛ فایل `600`). سپس `sudo systemctl restart capitalpilot`.
* کلید را در گزارش خطا، تیکت یا چت نگذارید؛ در صورت نشت، در پنل ارائه‌دهنده باطل کنید و کلید تازه وارد کنید.

## ۴) امنیت اتصال‌های خروجی

* آدرس‌های شبکهٔ داخلی/localhost به‌طور پیش‌فرض مسدودند (جلوگیری از SSRF): `PRICE_ALLOW_PRIVATE_HOSTS=false`. فقط برای سرویس خودتان `true` کنید.
* می‌توانید میزبان‌های مجاز را محدود کنید: `PRICE_API_ALLOWED_HOSTS=api.example.com,data.example.org`.

## ۵) زمان‌بند

زمان‌بند داخل همان فرایند است (`SCHEDULER_ENABLED=true`، `SCHEDULER_TICK_SECONDS=30`). فقط یک worker اجرا می‌شود. ساعات بورس تهران: شنبه تا چهارشنبه ۰۸:۴۵–۱۲:۴۵ به وقت تهران (`TSE_OPEN_TIME`/`TSE_CLOSE_TIME`)؛ مطمئن شوید ساعت سرور درست است: `timedatectl` (برنامه خودش با منطقهٔ `Asia/Tehran` حساب می‌کند).
تعطیلات رسمی شناسایی نمی‌شود.

## ۶) عیب‌یابی

| نشانه | اقدام |
|---|---|
| «تست اتصال» timeout می‌دهد | مسدودسازی IP خارجی یا فایروال؛ از خود سرور با `curl` بررسی کنید |
| خطای SSRF/«میزبان مجاز نیست» | آدرس را در `PRICE_API_ALLOWED_HOSTS` بگذارید یا آدرس عمومی بدهید |
| کلید قبلاً ذخیره‌شده کار نمی‌کند | `SECRET_KEY` عوض شده؛ کلید را دوباره وارد کنید |
| همهٔ قیمت‌ها «قدیمی» | منبع قطع است یا آینهٔ کش‌دار؛ «دریافت‌ها و سلامت» و «لاگ‌ها» را ببینید |
| لاگ‌ها | `journalctl -u capitalpilot -f` و `/var/log/capitalpilot` |
